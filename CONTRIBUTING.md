# Contributing to Live Neon Agent Identity

Thanks for your interest in contributing! This repo contains the public-facing tools for the Live Neon Persona platform.

## What You Can Contribute

- **Skills** — new platform skills or improvements to existing ones
- **Examples** — integration examples in new languages or frameworks
- **Cookbook** — guides for common use cases
- **MCP Server** — bug fixes, new tools, resource improvements
- **Documentation** — typo fixes, clarity improvements, new sections

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b my-feature`)
3. Make your changes
4. Test your changes
5. Commit with a clear message
6. Open a pull request

## Commit Messages

First line: **what** changed (`feat: add Go client example`). Body: **why**.

Optional identity footer:
- `Reflection:` — personal insight or how your thinking changed
- `Learnings:` — reusable principles discovered during the work
- `Reinforced:` — existing practice validated by this work

## Questions?

Open an issue or reach out at hello@liveneon.ai.
